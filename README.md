# Q1 - Read Employees API

## 📌 Project Overview

This project is a simple REST API built using **Node.js** and **Express.js**.

The API reads employee information from a `data.json` file and provides two GET endpoints:

- Get all employees
- Get a single employee by ID

The project uses the Node.js `fs` module to read employee data from the JSON file.
